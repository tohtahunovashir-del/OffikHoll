# OffikHoll

Нативный прототип приложения официанта для iPhone и iPad. Минимальная версия iOS — 16.0. Интерфейс полностью на русском.

## Реализовано

- Сетка из 12 столов с состоянием, суммой открытого заказа и переходом в заказ по нажатию.
- Экран заказа: быстрый выбор категории слева, блюда сеткой справа, добавление блюда одним нажатием, свернутая панель заказа и разворачиваемая детализация.
- Изменение количества, сохранение статуса «На кухне» и закрытие заказа со статусом «Оплачен».
- CRUD категорий и блюд, предварительное демонстрационное меню.
- Хранение меню, столов и заказов в локальной SQLite-базе через GRDB; SwiftData и сетевые вызовы из приложения не используются.
- Многостраничный OCR: фото с камеры или выбор нескольких изображений, локальная предобработка изображения, Vision OCR с выбором доступных языков, упорядочивание строк, контекстный разбор цен и заголовков категорий, редактирование/исключение позиций перед сохранением.
- Экспорт текущего меню и выбранных распознанных блюд в JSON/CSV через системное окно «Поделиться».
- Системная светлая/тёмная тема, системные материалы, тактильная обратная связь и Launch Screen с системным цветом фона.

> «На кухню» и «Оплата» здесь меняют локальный статус заказа; интеграция с внешней кассой, кухонным принтером и эквайрингом намеренно не заявлена.

## Сборка

Нужен macOS с Xcode и XcodeGen. В корне репозитория:

```sh
brew install xcodegen
xcodegen generate --spec project.yml
xcodebuild -resolvePackageDependencies -project OffikHoll.xcodeproj -scheme OffikHoll
xcodebuild -project OffikHoll.xcodeproj -scheme OffikHoll \
  -configuration Release -destination 'generic/platform=iOS' \
  CODE_SIGN_IDENTITY="" CODE_SIGNING_REQUIRED=NO CODE_SIGNING_ALLOWED=NO build
```

GitHub Actions выполняет генерацию Xcode-проекта, разрешение Swift Package, сборку без подписи и загружает ZIP с `.app` в artifacts.

## Ориентиры по UX

Структура заказа опирается на публично описанные сценарии iikoWaiter: работа со столами, быстрый ввод заказа и поиск блюд. Оффлайн-поведение, управление собственным меню и добавление позиций на ходу также характерны для публичного описания WaiterBolt. Это самостоятельная реализация на SwiftUI; код, изображения и фирменные материалы этих продуктов не копируются.
