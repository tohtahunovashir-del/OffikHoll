# OffikHoll

Премиальное iOS-приложение для официантов, повторяющее рабочий сценарий iikoWaiter:
карта зала, заказ в одно касание, счёт в нижней панели, оплата и закрытие стола.
Работает полностью офлайн — меню, столы и заказы хранятся в SQLite на устройстве.

## Что внутри

**Зал.** LazyVGrid карточек столов: номер, статус, сумма, число гостей и превью
позиций. Зоны («Основной зал», «Терраса», «Бар») фильтруются чипами. Тап по столу
открывает существующий счёт или создаёт новый — без лишних модальных окон.

**Заказ.** Слева вертикальный рельс категорий, справа сетка блюд. Тап по блюду
мгновенно добавляет его в заказ. Внизу — компактная панель с количеством позиций
и суммой; по тапу открывается детальный счёт: изменение количества, комментарий,
«На кухню», «Оплата», «Закрыть заказ». На iPad счёт — постоянно видимая третья
колонка (split-view, 340 pt).

**Меню.** Полный CRUD категорий и блюд, стоп-лист, поиск, иконки категорий и
экспорт в JSON/CSV. Кнопка «Сканировать меню» открывает сканер.

**Сканер меню (4 стадии).**
1. Документ-камера VisionKit выравнивает страницу; поддерживается многократное
   сканирование и импорт до 10 фото из галереи.
2. Core Image: grayscale, контраст 1.35, яркость, sharpen.
3. Vision `VNRecognizeTextRequest` `.accurate`, языки `ru/en/uk/be/de/fr/it/es`,
   фильтр уверенности, восстановление строк и колонок по геометрии bounding box.
4. `MenuParser`: цены `руб | р. | ₽ | грн | ₴ | $ | €`, десятичная запятая и точка,
   порции, лидеры-точки, переносы названий, автоопределение категорий. Затем —
   интерактивный экран проверки: редактируемые название/цена/категория, чекбоксы,
   предупреждения о низкой уверенности и дубликатах. В меню попадают только
   отмеченные строки.

**Настройки.** Название заведения и имя официанта, тема (системная/светлая/тёмная),
тактильный отклик, полная резервная копия JSON и восстановление, экспорт меню,
статистика базы и информация о версии.

## Архитектура

```
OffikHoll/
├── App/                @main, AppEnvironment, вкладки, маршруты
├── Database/           GRDB DatabaseQueue + миграции + демо-меню
├── Models/             struct-записи GRDB, снапшоты, модели сканера
├── Stores/             MenuStore, FloorStore, OrderStore (ValueObservation)
├── Services/           OCR, парсер меню, импорт, бэкап
├── DesignSystem/       палитра, типографика, компоненты, форматтеры, haptics
└── Features/
    ├── Floor/          карта зала, активные заказы, редактор стола
    ├── Order/          экран заказа, детали счёта, оплата
    ├── Menu/           меню, редакторы блюда и категории
    ├── Scanner/        документ-камера, прогресс OCR, проверка и импорт
    └── Settings/       настройки и данные
```

Жёсткие правила проекта:

- все модели — `struct`, `Codable + FetchableRecord + PersistableRecord`;
- единственное хранилище — GRDB/SQLite (SPM, версия 6.29.3), без SwiftData и без
  JSON-файлов вместо базы;
- каждый экран реактивен: мутации пишут в базу, `ValueObservation` сам обновляет
  `@Published`-снапшоты, ручных `reload()` нет;
- iOS 16.0 deployment target, только API, доступные на iOS 16;
- интерфейс полностью русский, тач-цели ≥ 44 pt, haptics на действиях и ошибках;
- светлая и тёмная темы, карточки с тенями и скруглениями.

## Сборка

```bash
brew install xcodegen
xcodegen generate
open OffikHoll.xcodeproj
```

GRDB подключается через Swift Package Manager автоматически
(`https://github.com/groue/GRDB.swift.git`, `from: 6.29.3`).
`Assets.xcassets` и `LaunchScreen.storyboard` включены в ресурсы явно — это
убирает чёрные полосы при старте.

### CI

`.github/workflows/ios-build.yml` на `macos-15`:

1. генерирует проект через XcodeGen;
2. восстанавливает `Package.resolved` и резолвит GRDB;
3. собирает под `generic/platform=iOS` без подписи
   (`CODE_SIGNING_ALLOWED=NO`);
4. упаковывает `.app` и `build.log` в артефакты `actions/upload-artifact@v4`.

## Статусы (как в iikoWaiter)

| Цвет | Статус | Значение |
|------|--------|----------|
| Золотой | Новый | заказ открыт, блюда ещё не отправлены |
| Зелёный | На кухне | пречек отправлен, готовится |
| Серый | Оплачен | счёт закрыт, стол свободен |

Столы с активным счётом получают золотую рамку и сумму; свободные — зелёный
акцент. Данные никогда не покидают устройство.
